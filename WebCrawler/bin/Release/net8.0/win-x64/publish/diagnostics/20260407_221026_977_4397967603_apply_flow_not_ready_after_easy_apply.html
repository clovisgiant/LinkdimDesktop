Desenvolvedor Backend

 

Local: Chácara Santo Antônio, São Paulo

Modelo: Híbrido (3x no escritório)

Nível: Sênior

Responsabilidades:

  • Participar do desenho da nova arquitetura backend e apoiar nas decisões de migração.
  • Desenvolver, manter e otimizar APIs e microsserviços escaláveis e seguros.
  • Garantir boas práticas de versionamento, testes automatizados e code review.
  • Apoiar o time no uso de padrões de design, arquitetura e integração contínua.
  • Identificar gargalos de performance e propor melhorias técnicas.
  • Colaborar com times de frontend, infraestrutura e dados para integração eficiente.
  • Atuar como mentor técnico para desenvolvedores júnior e pleno.

Requisitos técnicos:

  • Linguagens: Node.js ou Python (preferencial senioridade com Node).
  • Banco de Dados: Experiência sólida com SQL (PostgreSQL, MySQL) e NoSQL (MongoDB, Redis).
  • APIs: Criação e manutenção de APIs RESTful e GraphQL.
  • Arquitetura: Microsserviços, mensageria (Kafka, RabbitMQ) e containers (Docker, Kubernetes).
  • Cloud: Experiência com AWS, preferencialmente em projetos de migração.
  • CI/CD: GitHub Actions, Jenkins ou similares.
  • Boas práticas: Clean Code, SOLID, testes unitários e integração contínua.
