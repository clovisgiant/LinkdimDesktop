Job title: Oracle EBS Master Data Engineer

Duration: 12 months plus extensions

Start date: as soon as possible

Location: remote

Key Required Skills:

- Advanced English level.

- Strong experience in Master Data Management within enterprise IT environments.

- Experience working with Oracle EBS.

- Hands-on experience with Item Master Data.

- Solid understanding of data quality dimensions Accuracy, Completeness, Consistency, Validity.

- Strong SQL and/or data manipulation skills.

- Ability to operate independently and accelerate delivery.

- Experience working as part of a nearshore delivery model.
