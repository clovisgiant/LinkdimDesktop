Sobre a vaga

Estamos em busca de um Desenvolvedor Full-Stack Pleno para atuar no desenvolvimento, evolução e manutenção de aplicações web, participando ativamente das decisões técnicas e contribuindo com boas práticas de arquitetura, qualidade e performance.

Responsabilidades:

  • Desenvolver e manter aplicações front-end e back-end
  • Criar, consumir e manter APIs REST
  • Trabalhar com bancos de dados relacionais e não relacionais
  • Analisar requisitos e propor soluções técnicas
  • Corrigir bugs, otimizar performance e apoiar melhorias contínuas
  • Colaborar com o time em revisões de código e boas práticas
  • Documentar soluções e processos técnicos

Requisitos:

  • Experiência sólida com JavaScript/TypeScript
  • Vivência com Node.js no back-end
  • Experiência em front-end (React, Angular ou Vue)
  • Conhecimento em bancos de dados (PostgreSQL, MySQL, MongoDB ou similares)
  • Experiência com APIs REST
  • Uso de Git para versionamento de código
  • Capacidade de trabalhar de forma autônoma e colaborativa

Diferenciais:

  • Experiência com Node-RED
  • Conhecimento em Docker
  • Vivência com CI/CD
  • Experiência em ambientes de Indústria 4.0, IoT ou integrações de sistemas
  • Conhecimento em cloud (AWS, Azure ou GCP)
