Sobre a vaga

🚀 Desenvolvedor(a) Fullstack Júnior | Python + Next.js | Teresina - PI

  • Estamos em busca de um(a) Desenvolvedor(a) Fullstack Júnior apaixonado(a) por tecnologia e com vontade de crescer junto com o nosso time. Se você curte resolver problemas reais com código limpo e tem energia pra aprender no dia a dia, essa vaga é pra você!

💻 Responsabilidades

  • Desenvolver e manter APIs RESTful com Python + FastAPI
  • Contribuir no desenvolvimento de interfaces com Next.js e Vite.js
  • Participar de todo o ciclo de desenvolvimento: levantamento de requisitos, implementação, testes e entrega
  • Colaborar com o time em metodologias ágeis (Scrum/Kanban)
  • Escrever código limpo, documentado e testável
  • Apoiar na integração entre frontend e backend

✅ Requisitos Obrigatórios

  • Conhecimento em Python (lógica, orientação a objetos, boas práticas)
  • Familiaridade com FastAPI ou disposição para aprender rapidamente
  • Conhecimento em JavaScript/TypeScript e fundamentos de React
  • Noções de Next.js ou Vite.js
  • Experiência com Docker e ambientes containerizados
  • Versionamento com Git/GitHub
  • Conhecimento básico em banco de dados relacionais (PostgreSQL ou MySQL)
  • Habilidade de comunicação e trabalho em equipe

⭐ Diferenciais (não obrigatórios)

  • Conhecimento em ferramentas de CI/CD
  • Familiaridade com metodologias ágeis (Scrum/Kanban)
  • Experiência com consumo e criação de APIs REST
  • Conhecimento em testes automatizados (pytest, Jest)
  • Inglês técnico para leitura de documentação
