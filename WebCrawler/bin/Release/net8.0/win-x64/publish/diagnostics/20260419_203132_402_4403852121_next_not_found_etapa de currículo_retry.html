About Joveo:

Every company says they're "AI-first." We actually are. Joveo's recruitment

advertising platform processes millions of hiring decisions through machine

learning, real-time bidding, and predictive analytics — helping the world's

largest employers find the right people, faster and fairer. But we're not

done. Not even close.

Role: Junior Python Developer

Location: Remote

Role Overview:

We are hiring a Junior Python Developer to build your Python career

on Joveo's production backend. You will write real Python at scale —

APIs, services, and data pipelines — while growing under the guidance

of senior Python engineers on a team that ships fast.

Key Responsibilities:

- Develop Python backend services, REST APIs, and data processing code

- Write unit and integration tests to maintain code quality and reliability

- Contribute to feature delivery from requirements through production deployment

- Participate in design discussions and learn systems thinking through doing

- Fix production bugs and improve existing services for performance and clarity

- Deepen your expertise in frameworks like FastAPI, Django, or Flask

Required Skills & Qualifications:

- 1–2 years of hands-on Python development experience

- Solid understanding of Python 3 idioms, OOP, and common standard library modules

- Experience with at least one Python web framework in a production or project setting

- Working knowledge of SQL and relational databases

- Familiarity with Git, code review practices, and modern development workflows

- Ability to work independently on well-scoped tasks while asking for help when needed
