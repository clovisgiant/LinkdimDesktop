Responsibilities:

  • Design, develop, and maintain scalable enterprise-level web applications using React.js

  • Integrate frontend applications with .NET APIs and backend services
  • Collaborate with cross-functional teams including backend developers, product managers, and UI/UX designers
  • Ensure performance optimization, responsiveness, and high-quality user experience across applications
  • Develop reusable components and maintain consistent UI standards
  • Work with Azure services for deployment, data handling, and application scalability

  • Participate in code reviews and follow best practices for clean and maintainable code

Required Skills:

  • Strong experience with React.js and modern JavaScript (ES6+)
  • Hands-on experience integrating React applications with .NET APIs
  • Experience working with Microsoft Azure (App Services, Functions, Storage, etc.)
  • Proficiency in HTML5, CSS3, and responsive design principles
  • Experience with RESTful APIs and asynchronous programming
  • Familiarity with state management libraries (Redux, Context API, etc.)
  • Strong problem-solving and debugging skills

Nice to Have:

  • Experience with Highcharts or similar data visualization tools
  • Experience building analytics dashboards and reporting solutions
