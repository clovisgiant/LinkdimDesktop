Frontend Developer (React)

Desired Skills:

  • Experience with React JS development (4+ years)
  • Experience working with a state management library (Redux)
  • Strong knowledge of UX/UI (User Experience and User Interface Design)
  • Experience with prototyping tools (Figma, Adobe XD or any other)
  • Capability to develop responsive websites
  • Knowledge in modern JavaScript (ES6+)
  • Knowledge in TypeScript
  • Ability to write unit tests and end to end tests.
  • Professional proficiency in English

Bonus Skills:

  • Experience with Material-UI framework or any component library
  • Knowledge in Jest or Cypress testing frameworks
  • Design experience with any application like Sketch, Photoshop, Illustrator, etc.

What You’ll Do:

  • Plan, Design and Build front interfaces using ReactJS
  • Participate in daily Scrum meetings
  • Practice DevOps: write good test and deploy continuously

Qualifications:

  • 4+ years of experience with web technologies, including React, Redux, JavaScript, HTML, and CSS
  • Bachelor’s degree in computer science, Engineering, a related technical degree, or equivalent professional experience
  • Professional proficiency in English
